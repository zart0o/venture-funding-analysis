# Исследование венчурного рынка: закономерности финансирования стартапов

## Задача

Финансовая венчурная компания изучает исторические данные о стартапах, чтобы найти закономерности финансирования и выбрать стратегию инвестиций на 2015 год: в какую отрасль вкладываться и какой тип финансирования использовать.

## Данные

- данные о финансировании 54 294 компаний до 2014 года: суммы, раунды, типы финансирования, сегменты рынка, даты;
- годовые суммы возвратов по типам финансирования за 2000–2014 годы.

## Что сделано

1. **Предобработка:** нормализация названий столбцов, приведение сумм и дат к нужным типам, обработка пропусков и дубликатов, восстановление даты среднего раунда. В рабочем датасете осталось 40 907 компаний.
2. **Инжиниринг признаков:** группы компаний по сроку финансирования; разделение 849 рыночных сегментов на массовые, средние и нишевые.
3. **Выбросы:** поиск аномального финансирования методом IQR отдельно по каждому сегменту, ограничение периода годами с достаточным числом раундов.
4. **Анализ:** объём и популярность типов финансирования, динамика размера и количества раундов, рост сегментов в 2014 году, доля возвращённых средств по типам финансирования.

## Ключевые выводы

- 59% компаний получили финансирование всего один раз, но основная часть инвестиций приходится на компании, которые привлекали деньги дольше года.
- Рынок сильно раздроблен: из 849 сегментов 714 — нишевые, массовых всего 54.
- Типичный объём финансирования одной компании — около $2 млн.
- Начиная с середины 2000-х количество раундов растёт, а типичный размер одного раунда снижается: деньги распределяются между большим числом небольших сделок.
- Venture лидирует по объёму возвращённых средств, а наиболее устойчивый рост доли возврата показывает private equity.

## Рекомендация

Концентрировать вложения в растущих массовых сегментах, связанных с интернет-сервисами и технологиями. Для умеренно-консервативной стратегии — использовать private equity и долговое финансирование, а venture, seed и angel — точечно, как более рискованную часть портфеля.
